# Wiki Race Extension

Wiki Race Extension is a browser extension that finds a navigation path between a starting Wikipedia page and a target Wikipedia page across any supported language.

## Features

- Find a path between two Wikipedia articles.
- Support different Wikipedia languages.
- Simple browser extension workflow.
- Useful for wiki racing, exploration, and research.

## How it works

The extension takes:
- A start page
- A target page
- A selected Wikipedia language

It then searches for a possible path between the two articles and helps the user navigate from the starting article to the destination article.

## Use cases

- Play WikiRace more efficiently
- Explore connections between topics
- Discover related Wikipedia pages
- Test article link paths in different languages

## Project structure

- `manifest.json` — extension configuration
- `background.js` — background logic
- `content.js` — page interaction logic
- `searchManager.js` — search/path management
- `wikisearch.js` — Wikipedia search logic
- `style.css` — extension styles

## Installation

1. Download or clone this repository.
2. Open your browser extension page.
3. Enable Developer mode.
4. Load the extension as an unpacked extension.
5. Select this project folder.
